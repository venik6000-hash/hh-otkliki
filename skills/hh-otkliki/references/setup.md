# Настройка: первый запуск

Цель: собрать всё, что нужно для волн, за одну сессию. Результат — рабочая папка с профилем, карьерной базой, списком резюме, реестром и скриптами.

Говори с человеком простым языком. Задавай вопросы группами по 3–5, не одним длинным списком. Если ответ уже есть в резюме, не спрашивай его снова, а покажи и попроси подтвердить.

## Шаг 1. Рабочая папка

1. Спроси, где создать рабочую папку. По умолчанию предложи `~/hh-otkliki/`.
2. Создай структуру:

   ```
   <папка>/
   ├── hh-otkliki.md          # маркер и настройки скилла
   ├── профиль.md             # цели, условия, стоп-факторы, ответы для анкет
   ├── карьерная_база.md      # кейсы с кодами и границы достоверности
   ├── резюме_hh.md           # резюме на hh, хэши, правило выбора
   ├── реестр.md              # все отклики
   ├── волны/                 # отчёты волн
   ├── исходники/             # резюме и материалы человека
   ├── tmp/                   # рабочие материалы волн, можно удалять
   └── _tools/                # скрипты скилла
   ```

3. Скопируй из папки `templates/` скилла в корень рабочей папки: `hh-otkliki.md`, `CLAUDE.md`, `профиль.md`, `карьерная_база.md`, `резюме_hh.md`, `реестр.md`. `CLAUDE.md` подскажет новой сессии, что здесь работает скилл.
4. Скопируй `templates/отчёт_волны.md` в `волны/_шаблон.md`.
5. Скопируй папку `scripts/` скилла в `<папка>/_tools/`.
6. Проверь скрипты: `python3 _tools/letters.py --help`. Если Python нет, скажи человеку и продолжай без скриптов: проверки делай вручную по тем же правилам.

## Шаг 2. Резюме

1. Попроси резюме. Подойдёт любой вариант:
   - файл PDF, DOCX или текст;
   - ссылка на резюме hh;
   - рассказ голосом или текстом.
2. Сохрани копию в `исходники/`.
3. Если резюме на hh уже есть, открой `https://hh.ru/applicant/resumes` в браузере человека. Для каждого резюме запиши в `резюме_hh.md` название, хэш из ссылки `/resume/<хэш>` и статус видимости.
4. Если у человека несколько резюме на hh, спроси правило выбора: какое резюме для каких ролей.

**Внимание:** resumeId (число) нужен для сверки откликов. Получи его на шаге проверки первой волны по [hh-verify.md](hh-verify.md) и допиши в `резюме_hh.md`.

## Шаг 3. Вопросы о поиске

Задай вопросы по группам. Ответы запиши в `профиль.md`.

**Цель и роли:**

1. Какие должности ищете? Назовите 2–5 вариантов.
2. Какой уровень: специалист, ведущий, руководитель?
3. В каких отраслях или продуктах хотите работать? Где точно не хотите?

**Условия:**

1. Формат: удалёнка, гибрид, офис? Если офис, то в каком городе?
2. Где вы живёте и в каком часовом поясе? Готовы ли к переезду?
3. Зарплатные ожидания: минимум и желаемая сумма. Фильтровать ли вакансии по зарплате?
4. Английский и другие языки: какой реальный уровень?

**Стоп-факторы.** Спроси прямо: «Что в вакансии значит "точно нет"?» Предложи примеры:

- требуется язык выше вашего уровня;
- требуется навык, которого нет (стек, инструмент, лицензия);
- роль по сути про продажи или холодные звонки;
- нежелательная отрасль;
- обязательный офис;
- тестовое задание до первого разговора.

**Анкеты работодателей.** hh часто задаёт вопросы до отправки. Собери готовые ответы:

1. Контакт для связи: Telegram, почта или телефон. Возьми только то, что человек сам готов дать.
2. Город и часовой пояс для анкеты.
3. Ссылки на портфолио, GitHub, кейсы.
4. Как отвечать на вопрос о зарплате.

**Режим работы:**

1. Сколько откликов в одной волне? По умолчанию 5–10.
2. Показывать ли все письма перед отправкой или только первые три?
3. Отправлять ли агенту самому после одобрения или человек отправит сам?
4. Тон писем: нейтральный или разговорный?

## Шаг 4. Карьерная база

Карьерная база — главный источник фактов для писем. Без неё письма выходят общими.

1. Разбери резюме на отдельные кейсы. Кейс — одна задача, которую человек решил на работе или в проекте.
2. Дай каждому кейсу код: К1, К2, К3…
3. Для каждого кейса заполни поля шаблона:
   - исходная ситуация;
   - личное действие человека;
   - результат и его статус: измерено, оценка, наблюдение, прототип, план;
   - для каких вакансий кейс подходит;
   - что нельзя утверждать.
4. Если в резюме нет результата или личного вклада, спроси человека. Задавай вопросы по одному кейсу за раз.
5. Запиши в раздел «Границы достоверности» то, что нельзя писать: NDA-клиенты, приукрашенные статусы, навыки, которых нет.
6. Заполни «Индекс выбора»: таблица «тип задачи вакансии → код кейса».

**Запрещено:** придумывать цифры, результаты и формулировки, которых человек не подтвердил. Если факта нет, поставь пометку `TODO: уточнить` и спроси.

## Шаг 5. Проверка и запуск

1. Покажи человеку краткую сводку: роли, условия, стоп-факторы, число кейсов, режим работы.
2. Попроси исправить ошибки.
3. Запиши в `hh-otkliki.md` дату настройки.
4. Предложи первую пробную волну на 3–5 откликов с показом всех писем.
