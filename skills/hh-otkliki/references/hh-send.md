# Механика hh.ru: отправка, ввод текста, правка резюме

## Вкладки

Если одновременно работают несколько агентов, каждый открывает свою вкладку и работает только с её ID.

**Запрещено:** трогать и закрывать чужие вкладки. Соседний агент потеряет контекст на середине отклика.

## Отправка отклика

Страницу вакансии в браузере открывает только отправщик. Здесь впервые видны форма и вопросы анкеты.

**Резюме** выбирай по правилу в `резюме_hh.md` рабочей папки.

**Первый клик по «Откликнуться» часто не открывает форму.** Всплывает зелёный тост с призывом откликаться. Если формы нет, закрой тост и кликни ещё раз по координатам кнопки. Клик через `ref` иногда не срабатывает.

**hh предвыбирает не то резюме.** Названия похожих резюме могут отличаться одним словом. В модалке и на странице анкеты предвыбор бывает разным.

**Внимание:** отозвать отклик hh не даёт. Ошибку исправляет только второй отклик через «Отклик другим резюме», и у работодателя остаются два.

Перед каждой отправкой проверь выбранное резюме. Надёжнее всего сверять хэш резюме в состоянии формы с хэшем из `резюме_hh.md`.

**Форма бывает двух видов:**

- модалка на странице вакансии;
- отдельная страница `/applicant/vacancy_response` с вопросами анкеты.

Обычная анкета не стоп-фактор. Ответы бери из `профиль.md`. Если на вопрос нужны слова человека, остановись на этой вакансии. Такие вопросы собери за проход и задай одним сообщением.

**hh сохраняет черновик письма** и подставляет его при повторном открытии формы. `Ctrl+A` в этом поле не выделяет содержимое, правка даёт задвоение хвоста.

1. Очисти поле нативным сеттером (приём ниже).
2. Набери текст заново.
3. До отправки сверь длину текста в поле с длиной письма.

**После отправки DOM обновляется с задержкой 5–8 секунд.** Скриншот сразу после клика белый, текста «Вы откликнулись» ещё нет.

**Внимание:** ранняя проверка даёт ложное «не отправлено» и провоцирует повторную отправку. Подожди и проверь по [hh-verify.md](hh-verify.md).

**Баннер «Вы откликаетесь на вакансию в другой стране»** не блокер для удалённых вакансий. Продолжай через «Все равно откликнуться».

**Диалог с просьбой указать город** иногда всплывает после отправки. Это изменение профиля: закрой крестиком.

**Апселл.** На страницах hh много платных кнопок рядом с «Откликнуться»:

- «Поднять в поиске»;
- «Усилить отклик»;
- «Хочу hh PRO».

**Запрещено:** оплачивать что-либо.

Если экран увёл на оплату, вернись назад и отметь это в отчёте.

## Ввод текста в формы

Формы hh написаны на React. Отсюда две проблемы:

- страница дорендеривается после загрузки и стирает введённое;
- присваивание `element.value = ...` не доходит до состояния React, сохранение молча не срабатывает.

Порядок для короткого текста:

1. Подожди 4–6 секунд после открытия формы.
2. Сделай скриншот и найди поле визуально.
3. Кликни мышью внутрь поля, не через JS-focus.
4. Нажми `cmd+a` (или `ctrl+a`), затем `Delete`.
5. Проверь через JS, что длина значения стала 0. Если нет, повтори клик по другим координатам.
6. Напечатай текст настоящим набором.
7. Проверь через JS по характерному фрагменту, что текст на месте.

Без шагов 5 и 7 легко отправить смесь старого и нового текста.

**Приём для длинного текста.** Посимвольный набор 4000 знаков упирается в таймауты браузера.

1. Поставь значение нативным сеттером: `Object.getOwnPropertyDescriptor(window.HTMLTextAreaElement.prototype,'value').set.call(ta, newText)`.
2. Отправь событие: `ta.dispatchEvent(new Event('input',{bubbles:true}))`.
3. Кликни мышью в поле, нажми `cmd+Down`, напечатай точку настоящим набором, затем `Backspace`. Настоящее нажатие заставляет React прочитать поле целиком.
4. Проверь, что React увидел текст: длина `ta[Object.keys(ta).find(k=>k.startsWith('__reactProps'))].value` равна длине `ta.value`.

## Правка резюме

Правь резюме только по прямой просьбе человека.

**Страница резюме показывает только три блока опыта.** Полный состав и результат правки проверяй в печатной версии `https://hh.ru/resume/<хэш>?print=true`.

**Опыт работы хранится в профиле, а не в резюме.** К резюме запись привязывают галочки «Резюме с этим местом работы». Следствия:

- Дубликат резюме использует те же записи опыта. Правка в дубликате меняет и оригинал. Чтобы описать компанию по-разному, создай новую запись с галочкой только у нужного резюме.
- «Удалить» убирает запись из всех резюме сразу. Чтобы убрать запись из одного резюме, сними галочку.
- Новое резюме появляется в списке галочек только после публикации.
- Мастер «Дополнить» при публикации перезаписывает название резюме и стирает специализации. После публикации проверь и верни их.
- Маршрут `/profile/edit/experience/N?resumeFrom=<хэш>` рендерит пустую страницу. Работает `/profile/edit/experience/N?hhtmFrom=applicant_profile`.
- Лимит описания места работы около 4096 знаков.

Записи опыта с кнопками редактирования: `https://hh.ru/applicant/resumes/edit/experience?resume=<хэш>`. Прочие страницы: `/resume/edit/<хэш>/position`, `/about`, `/contacts`, `/visibility`, `/keySkills`.

Селекторы полей опыта: `[data-qa="resume-editor-experience-company-input"]`, `-position-input`, `-start-year-input`, `-end-year-input`, `-description-input`. Месяц выбирается в кастомном списке `[data-qa="resume-editor-experience-start-month-input"]`: кликни и выбери пункт по тексту.

**Навыки.** Лимит 30 тегов. При превышении hh пишет «Количество навыков превышено на N элементов» и не сохраняет.

- Чип удаляется обычным `.click()` по `button[aria-label="Удалить"]` внутри чипа.
- Новые навыки вводи настоящим набором. Перевод строки работает как Enter, поэтому несколько навыков можно ввести одной строкой через `\n`.
- После сохранения hh открывает экран уровней владения. Проставь уровень каждому новому тегу, иначе форма не закроется.
