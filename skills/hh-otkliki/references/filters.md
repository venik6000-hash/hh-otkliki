# Отбор вакансий

Цели, условия и стоп-факторы человека — в `профиль.md` рабочей папки. Здесь только механика отбора.

Пересечение пула с `реестр.md` проверяй до чтения описаний.

## Порядок решения

1. Если в вакансии есть стоп-фактор из `профиль.md`, пропусти её. Причину подтверди цитатой.
2. Если роль совпадает с целевыми ролями по сути работы, бери вакансию. Заголовок сам по себе не решает.
3. Если требование неоднозначно, пометь «сомнение» и покажи человеку после основного списка.

Приоритет у вакансий, где отбирают по доказанной практике и измеримому результату, а не по формальному стажу в должности.

## Общие стоп-факторы

Эти пункты действуют, если `профиль.md` не говорит иначе:

- Уже стоит отметка «Вы откликались».
- Обязательное тестовое внутри формы или анкета, где нужно придумать кейсы за человека. «Тестирование следующим этапом» не стоп-фактор.
- Требование сменить видимость резюме. Это стоп до решения человека.
- Партнёрская схема: доход целиком от приведённых клиентов, вилка вида 50–450 тыс.

**Не стоп-факторы:** обычная анкета с зарплатой, языком и контактами. Ответы бери из `профиль.md`.

Формулировки «английский приветствуется» и «чтение документации» не равны требованию свободного английского. Сверяй с уровнем человека из профиля.

## Заголовки-ловушки

Некоторые заголовки похожи на целевую роль, но по сути другие. Типичные примеры:

- тренер или разметчик данных для нейросетей, асессор;
- менеджер по продажам продукта под видом продуктовой роли;
- «консультант» или «амбассадор» с оплатой за приведённых клиентов;
- «партнёр по рекомендациям».

Если находишь новую ловушку для профессии человека, предложи добавить её в `профиль.md`.

## Сколько вакансий на самом деле есть

Подходящих вакансий может быть меньше, чем просит человек. На задачу «откликнись на 20» честно скажи, сколько набралось строго по профилю. Спроси, добирать ли смежными ролями.

**Запрещено:** молча расширять фильтр, чтобы добить до числа.

## Формулировки резюме проверять частотностью

Новый заголовок резюме или ключевой навык предлагай только после замера частотности:

1. Открой `https://hh.ru/search/vacancy?text=<запрос>&search_field=name&area=113`. Для удалёнки добавь `&work_format=REMOTE`.
2. Возьми количество из JSON в `<template id="HH-Lux-InitialState">`, поле `vacancySearchResult.totalResults`.
3. Сравни минимум 5–8 вариантов.

Составной заголовок из частотного русского ядра, латинского эквивалента и отличительной детали обычно выигрывает у одиночного узкого.
