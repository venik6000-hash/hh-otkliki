# hh-otkliki: отклики на hh.ru с помощью Claude

Скилл для Claude, который ведёт поиск работы на hh.ru. Он находит подходящие вакансии, пишет персональное сопроводительное письмо к каждой и отправляет отклики после вашего одобрения.

Письмо строится от текста конкретной вакансии и ваших проверяемых фактов. Скилл не рассылает один шаблон на сотню вакансий.

## Что делает скилл

1. **Настройка.** При первом запуске задаёт вопросы о целях и условиях, просит резюме и собирает карьерную базу: ваши кейсы с результатами. Создаёт рабочую папку.
2. **Волна откликов.** По команде «запусти волну» собирает свежие вакансии, читает каждую целиком и отсеивает неподходящие по вашим стоп-факторам.
3. **Отбор.** Показывает список: позиция, ссылка, почему подходит.
4. **Письма.** Пишет короткое письмо к каждой вакансии на 600–900 знаков. Один сильный аргумент, только подтверждённые факты.
5. **Отправка.** После вашего «да» отправляет отклики через браузер и проверяет, что всё ушло нужным резюме.
6. **Учёт.** Ведёт реестр откликов и сверяет статусы с кабинетом hh.

## Что нужно

- **Claude** с поддержкой скиллов: Claude Code, Claude Desktop или claude.ai.
- **Управление браузером:** расширение Claude in Chrome или встроенный браузер Claude Desktop. Без браузера скилл работает в ручном режиме: готовит отбор и письма, отправляете вы.
- **Аккаунт на hh.ru**, в который вы вошли сами. Скилл никогда не вводит пароли.
- **Python 3** для небольших скриптов проверки. На macOS и Linux обычно уже есть.

## Установка

### Вариант 1. Попросить Claude (проще всего)

Напишите Claude в Claude Code или Claude Desktop:

```
Установи скилл из https://github.com/venik6000-hash/hh-otkliki
```

Claude прочитает раздел «Для агента» ниже и всё сделает.

### Вариант 2. Плагин Claude Code

```
/plugin marketplace add venik6000-hash/hh-otkliki
/plugin install hh-otkliki@hh-otkliki
```

### Вариант 3. claude.ai или Claude Desktop через ZIP

1. Скачайте `hh-otkliki.zip` со страницы [Releases](https://github.com/venik6000-hash/hh-otkliki/releases/latest).
2. Откройте «Настройки» → «Возможности» (Capabilities) → «Навыки» (Skills).
3. Нажмите «Загрузить навык» и выберите ZIP.

## Как пользоваться

1. Напишите Claude: «Хочу искать работу на hh, настрой поиск».
2. Ответьте на вопросы и пришлите резюме. Настройка занимает 15–30 минут.
3. Войдите в hh.ru в браузере, которым управляет Claude.
4. Напишите: «Запусти волну на 5 откликов».
5. Проверьте список вакансий и письма. Поправьте, если нужно.
6. Скажите «отправляй» или отправьте сами.
7. Через 3–4 дня попросите: «Сверь статусы откликов».

Первую волну лучше сделать пробной: 3–5 откликов, все письма на проверку.

## Рабочая папка

После настройки появится папка (по умолчанию `~/hh-otkliki/`):

| Файл | Что внутри |
|---|---|
| `профиль.md` | Цели, условия, стоп-факторы, ответы для анкет |
| `карьерная_база.md` | Ваши кейсы с кодами и границы: что нельзя писать |
| `резюме_hh.md` | Резюме на hh и правило выбора |
| `реестр.md` | Все отклики и их статусы |
| `волны/` | Отчёты волн с полными текстами писем |
| `tmp/` | Рабочие материалы, можно удалять |

Файлы можно править руками. Чем точнее карьерная база, тем сильнее письма.

## Безопасность

- Скилл не вводит пароли, коды и платёжные данные.
- Скилл не отправляет отклики и не отвечает работодателям без вашего разрешения.
- Скилл не нажимает платные кнопки hh («Поднять в поиске», «Усилить отклик», hh PRO).
- Скилл не придумывает факты. Если факта нет в карьерной базе, он спросит вас.
- Ваши данные остаются в рабочей папке на вашем компьютере.

**Внимание:** отозвать отклик на hh нельзя. Проверяйте письма перед отправкой, особенно в первых волнах.

## Состав репозитория

```
skills/hh-otkliki/
├── SKILL.md               # точка входа: режимы и порядок волны
├── references/            # настройка, фильтры, метод письма, механика hh
├── templates/             # шаблоны файлов рабочей папки
└── scripts/               # letters.py, registry.py, state.py
```

## Для агента: как установить

Если пользователь просит установить этот скилл:

1. Определи среду.
2. **Claude Code или Claude Desktop с доступом к файлам:**
   1. Склонируй репозиторий во временную папку: `git clone --depth 1 https://github.com/venik6000-hash/hh-otkliki.git <tmp>`.
   2. Скопируй `<tmp>/skills/hh-otkliki` в `~/.claude/skills/hh-otkliki`. Если папка уже есть, спроси пользователя, заменить ли её.
   3. Удали временную папку.
   4. Скажи пользователю, что скилл установлен. Если скилл не появился в списке, попроси перезапустить сессию.
3. **claude.ai без доступа к файлам:** дай пользователю ссылку на ZIP из Releases и шаги варианта 3.
4. Предложи сразу начать настройку: «Хочу искать работу на hh, настрой поиск».
